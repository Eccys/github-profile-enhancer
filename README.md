## ✨ Features

* **Interactive CLI Tool:** Run a single Python command to customize your profile headers, taglines, tech stack, and social channels.
* **Curated Premium Badges:** Access a high-quality list of Shields.io badges for programming languages, frameworks, developer tools, and databases.
* **Dynamic Analytics Widgets:** Seamlessly integrate live GitHub stats, language breakdowns, and commit streak calendars.
* **Built-in Monetization Templates:** Easily add support links (Ko-fi, Buy Me A Coffee, PayPal) to receive sponsorships and donations directly from your profile visitors.

## 🚀 Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/github-profile-enhancer.git
cd github-profile-enhancer
```

### 2. Run the Generator Script
No external dependencies or pip libraries required! Just run:
```bash
python3 generator.py
```

### 3. Generate and Publish
Follow the interactive CLI prompts to select your skills, tools, and links. The script will instantly compile your layout into a file named `SAMPLE_README.md`. 
Copy its contents and paste them into your personal profile repository (e.g. `https://github.com/username/username`).

## 🛠️ Data and Customization
All tech stack badge definitions are located in `data.json`. You can easily add, update, or remove badges and custom colors:
